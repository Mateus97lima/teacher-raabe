# Teacher Raabe — Landing Page

Landing page profissional para Teacher Raabe, desenvolvida com Next.js 14, TypeScript e Tailwind CSS.

## 🚀 Como rodar o projeto

### Pré-requisitos
- Node.js 18+
- npm ou yarn

### Instalação

```bash
# 1. Instale as dependências
npm install

# 2. Rode em desenvolvimento
npm run dev

# 3. Acesse no navegador
http://localhost:3000
```

### Build para produção

```bash
npm run build
npm start
```
