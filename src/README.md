# 🎓 Teacher Raabe — Landing Page

> Landing page profissional para aulas de inglês online, desenvolvida com **Next.js 14**, **TypeScript** e **Tailwind CSS**.




## 📁 Estrutura do projeto

```
teacher-raabe/
├── src/
│   ├── app/
│   │   ├── layout.tsx        # Layout global + SEO
│   │   └── page.tsx          # Página principal
│   ├── components/
│   │   ├── Navbar.tsx        # Navegação responsiva com menu mobile
│   │   ├── Hero.tsx          # Seção principal com stats
│   │   ├── About.tsx         # Sobre a professora + curiosidades
│   │   ├── Etapas.tsx        # Método em 3 etapas
│   │   ├── Services.tsx      # Planos e preços
│   │   ├── Testimonials.tsx  # Depoimentos de alunos
│   │   ├── Contact.tsx       # Formulário → abre WhatsApp
│   │   └── Footer.tsx        # Rodapé
│   └── styles/
│       └── globals.css       # Estilos globais + Tailwind
├── tailwind.config.ts
├── tsconfig.json
├── next.config.js
└── package.json
```

---

## 🛠️ Tecnologias utilizadas

| Tecnologia | Versão | Uso |
|---|---|---|
| Next.js | 14 | Framework React com SSR |
| TypeScript | 5 | Tipagem estática |
| Tailwind CSS | 3.4 | Estilização utility-first |
| React | 18 | Biblioteca de UI |



## 📱 Responsividade

O site é totalmente responsivo e adaptado para:
- 📱 **Mobile** — menu hambúrguer, layout em coluna única
- 💻 **Tablet** — grid de 2 colunas nos cards
- 🖥️ **Desktop** — layout completo com sidebar no hero
